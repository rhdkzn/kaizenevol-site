# Fonts served from this repo

| File | Family | Licence |
|---|---|---|
| `manrope.woff2` | Manrope | SIL Open Font License 1.1 |
| `newsreader-italic.woff2` | Newsreader | SIL Open Font License 1.1 |
| `mono.woff2` | JetBrains Mono | SIL Open Font License 1.1 |
| `tag.woff2` | Sedgwick Ave Display | SIL Open Font License 1.1 |

Sedgwick Ave Display is used only for the founder names and roles under the
photo on `about.html`. It is a handstyle tag face, chosen over Permanent Marker
because that one is the default marker font on the web (Diego, 2026-09-11:
"that's a very basic font").

`fraunces*.woff2` and `pjs-*.woff2` are v2 leftovers, no longer referenced.
